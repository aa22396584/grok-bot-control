Help & reporting

Support

For usage questions, reproducible bugs, or feature ideas, open a GitHub issue. Search existing issues first and include the plugin version, host environment, expected behavior, and a minimal redacted reproduction.

Protect your data

Maintainers will not ask for passwords, access tokens, Telegram sessions, Grok credentials, private conversation exports, or remote computer access. Do not post those items in an issue, log, screenshot, or sample state file.

Security reports

If GitHub’s private vulnerability reporting option is available for the repository, use Report a vulnerability. If that route is unavailable, contact maintainer @ImL1s on GitHub without disclosing exploit details publicly, and wait for a private reporting route.

Scope

Community support is best-effort. There is no response-time commitment or service-level agreement. Problems in Grok Bot, Codex, operating systems, or optional third-party CLIs may need to be reported to their respective maintainers.
