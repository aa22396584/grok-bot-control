What it adds

A control layer for human-scale agent work.

The plugin supplies instructions and local decision helpers. The host and signed-in Grok Bot environment still perform the actual work.

01 / HANDOFF

Explicit ownership

Identify the current operator and conversation before a message is sent.

02 / SEND

No blind repeats

Classify draft, sent, acknowledged, and uncertain states to avoid duplicate prompts.

03 / WAIT

Bounded follow-up

Calculate wait, nudge, and escalation timing from a persistent state record.

04 / REVIEW

Evidence packages

Exchange sanitized artifacts, hashes, and acceptance notes between operators.

05 / WORKFLOWS

Practical playbooks

Guidance covers conversations, attachments, groups, routines, skills, and shared computers where host tools support them.

06 / PORTABLE

Local by design

No plugin backend, telemetry, hosted database, or bundled Grok credentials.

Local install

Two commands. Review the source first.

Add the repository as a local Codex marketplace, then install the plugin from that marketplace.

Requirements: a Codex environment with plugin support and, for live operations, host-provided computer-use tools plus your own signed-in Grok Bot session.

After installing, open a new Codex task and ask: Use $grok-bot-control to coordinate with my authorized Grok Bot conversation.

# Add the community marketplace codex plugin marketplace add ImL1s/grok-bot-control # Install the workflow plugin codex plugin add grok-bot-control@grok-bot-control-local
