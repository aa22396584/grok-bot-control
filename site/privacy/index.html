Policy

Privacy

Last updated September 8, 2026

Grok Bot Control is a local workflow plugin. The project does not operate a backend, analytics service, advertising system, or telemetry collector.

Data handled by the plugin

The assessment helpers read local state without network access. The delivery journal writes local target identifiers, operation scope, operator labels, timestamps, message digests, baseline message identifiers, and delivery outcomes; it does not store message text or credentials. The optional CLI adapter contacts Grok only when a live operation is explicitly enabled. It delegates authentication to a separately installed CLI, which may access the signed-in Grok Bot app session and macOS Keychain. A send passes your message to Grok; roster and transcript reads return account content to the invoking agent. Your host agent may process messages and tool output under its own provider policies. Keep private message files and journals outside this public repository.

Host and optional services

Your Codex host, Grok Bot environment, operating system, GitHub, and any optional CLI handle their own prompts, credentials, logs, and network traffic under their own policies. They are separate from this project. Never include credentials, session files, private chat contents, or personal data in bug reports.

This website

This static site does not set cookies or load analytics. GitHub Pages may process and log requests needed to serve the site under GitHub’s privacy statement.

Public reports

GitHub issues and discussions are public. Redact private information before posting. For a security concern, follow the private reporting instructions on the support page.
